# HeadlessBlog

> CMS-driven blog platform with ISR, MDX support, and zero-deployment content management — Next.js 15 + Payload CMS v3.

Built by [Aman Soni](https://github.com/amansoni1605) · [Portfolio](https://github.com/amansoni1605/portfolio)

## Tech Stack

| Layer | Technology |
|---|---|
| Framework | Next.js 15 (App Router) |
| CMS | Payload CMS v3 |
| Database | PostgreSQL + Drizzle ORM |
| Rich Text | Lexical (via Payload) |
| Content | MDX |
| Cache | ISR with on-demand revalidation |
| SEO | JSON-LD structured data |
| Styling | Tailwind CSS v4 |

## Features

- **Zero-deployment content** — Editors manage everything from Payload admin
- **ISR** — Pages revalidate on-demand via Payload webhooks, no full redeploy
- **Auto-generated TypeScript types** from Payload collections
- **MDX** — Rich in-content React components inside blog posts
- **JSON-LD** — Article structured data for search engine rich results
- **Draft/Publish workflow** — Preview unpublished posts before going live

## Getting Started

```bash
# Install dependencies
npm install

# Set up env
cp .env.example .env
# Fill in: DATABASE_URI, PAYLOAD_SECRET, NEXT_PUBLIC_SERVER_URL

# Run database migrations
npm run db:migrate

# Run development (Next.js + Payload admin on same port)
npm run dev

# Open blog:  http://localhost:3000
# Open admin: http://localhost:3000/admin
```

## Architecture Decisions

### ISR + On-demand Revalidation
Pages are statically generated at build time and revalidated via a Payload webhook whenever a post is published or updated. No manual redeploy needed for content changes.

### Type-safe content access
Payload generates TypeScript types from collection schemas automatically — no manual type definitions for content shapes.

```ts
// Auto-generated by Payload — types match the CMS schema exactly
import type { Post, Author, Tag } from '@/payload-types'

const post: Post = await payload.findByID({ collection: 'posts', id })
```
